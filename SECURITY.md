# Security Policy

## Reporting a Vulnerability

Please do not publicly disclose security vulnerabilities in a GitHub issue.

Use GitHub's private vulnerability reporting feature for the TraceTK repository when available.

Include enough information to understand and reproduce the issue, including:

* The affected TraceTK version or commit
* A description of the vulnerability
* Steps or code required to reproduce it
* The potential impact
* Any known mitigations or workarounds

Please avoid including sensitive information that is not necessary to investigate the report.

## Supported Versions

TraceTK is currently in early development and does not yet have a stable release support policy.

Security fixes will generally target the current development version until a formal versioning and support policy is established.
